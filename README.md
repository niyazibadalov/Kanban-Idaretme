#  Kanban İdarəetmə 

Müasir veb standartlarına və təmiz JavaScript (Vanilla JS) kod strukturuna uyğun hazırlanmış **Kanban İdarəetmə** tətbiqi.

---

## Xüsusiyyətlər 

* **Dinamik Render:** Tapşırıqların JS massivindən dinamik olaraq müvafiq sütunlara (`Gözləmədə`, `İcra olunur`, `Tamamlandı`) paylanması.
* **Avtomatik Sayğaclar:** Hər sütundakı tapşırıq sayının real vaxt rejimində yenilənməsi.
* **Təmiz Veb Strukturu:** BEM adlandırma konvensiyasına uyğun CSS və modulyar JavaScript kodu.

---

##  İstifadə Olunan Texnologiyalar

* **HTML5** (Semantik struktur)
* **CSS3** (Flexbox, CSS Grid, BEM)
* **JavaScript (ES6+)** (DOM manipulyasiyası, Dinamik Rendering)
